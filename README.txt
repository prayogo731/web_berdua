OUR LITTLE LOVE WORLD - Prayogo & Nastri

CARA PAKAI
1. Buka index.html dengan browser (perlu internet untuk musik YouTube & font).
2. Letakkan file Anda di folder assets dengan nama persis:
   assets/prayogo/prayogo1.jpg ... prayogo3.jpg
   assets/nastri/nastri1.jpg ... nastri18.jpg
   assets/couple/couple1.mp4, couple2.mp4
   assets/anime/sao.jpg, black-clover.jpg, doraemon.jpg, code-lyoko.jpg,
                mr-robot.jpg, naruto.jpg, boruto.jpg  (poster resmi)
3. Semua pengaturan (caption, lagu, pesan, kuis, alasan, koordinat peta)
   ada di bagian CONFIG di dalam <script> index.html.
4. Peta: isi mapCoords: {lat:..., lng:...} untuk Baturaja Bakung.

CATATAN
- File yang belum ada otomatis diganti kotak beruang imut.
- Nama penyanyi di CONFIG.songs sebaiknya dicek ulang.
- Musik diputar lewat embed resmi YouTube dan hanya setelah tombol Play ditekan.
